
# Lab 10 – Jenkins CI/CD Pipeline

This project demonstrates a Jenkins CI/CD pipeline for a Python application.

## Pipeline Stages
- Setup: Install Python dependencies.
- Lint: Check code using Flake8.
- Test: Run unit tests using pytest.
- Coverage: Generate a code coverage report.
- Security Scan: Scan the code using Bandit.
- Deploy: Perform a simple local deployment.

## Results
- Jenkins Build #3: Successful
- Code Coverage: 75%
- Security Issues: 0
- Local Deployment: Successful
